# 指标口径与评级规则说明

## 指标口径

以下均为本期暂定口径，正式业务规则尚未确认：

| 指标 | 公式 | 缺失语义 |
|---|---|---|
| 历史 GMV | 达人表各业务期间 `联盟 GMV` 之和 | 无来源值为 null |
| 出单件数 | 达人表各业务期间 `联盟商品成交件数` 之和 | 无来源值为 null |
| 合作后 GMV | 达人表各业务期间 `定向合作 GMV` 之和 | 无来源值为 null |
| 历史 ROI / 达人总 ROI | `预计佣金 / 合作成本 × multiplier` | 合作成本缺失或 0 时为 null |
| 达人费比 ROI | `合作后 GMV / 合作成本` | 合作成本缺失或 0 时为 null |
| 视频/直播归因 GMV | 对应明细表 `归因 GMV` 按达人求和 | 无来源值为 null |
| 单视频/单直播 ROI | `该条归因 GMV / 该条坑位费 × multiplier` | 该条坑位费缺失时为 null |
| 总视频/总直播 ROI | `Σ归因 GMV / Σ坑位费 × multiplier` | 任一应计明细缺坑位费时整体为 null |

达人表是期间快照，只能按横幅业务期间（无横幅时用稳定期间键，重导覆盖不累加）或“总”查看；视频/直播使用 UTC+7 行日期，支持日/周/月/年/总聚合。看板“总 GMV”是联盟 GMV，视频和直播卡片是归因 GMV 分段，三者不能相加当作新增 GMV。

## 评级规则（暂定）

- 默认指标及权重：历史 GMV 0.45、出单件数 0.25、合作后 GMV 0.30。
- 每项在当前库内做 min-max 归一到 0..100；全库同值时记 50。
- 缺失项排除，并按该达人剩余可用权重重新归一；全部缺失得 0。
- 默认档位：S `[80,100]`、A `[60,80)`、B `[40,60)`、C `[20,40)`、D `[0,20)`。
- `ratings.evidence_json` 保存原值、总体最小/最大值、归一分、权重、加权分、命中档位和规则哈希。

成本补录一定触发指标与等级重算，但默认评级权重不含 ROI，所以字母等级可能不变；这不代表重算未发生。

## 修改方法

浏览器打开 `/config` 可修改现有评级权重、四个共享档位边界、五类 ROI 字段/倍数/说明。保存后会写回 `config/rating_rules.json`、全量重算并逐键写入 `config_change_log`。也可在停服且已备份时编辑 JSON，再访问 `/recompute?full=1`。

`calculator_formula` 当前必须保持 `null`：业务未确认公式，系统不会猜测计算。正式口径到位后应先定义结构、校验、测试及版本迁移，再实现执行器。
